# The Flyway migrations a release has shipped, one per line: the SHA-256 of the file, two spaces,
# its repository-relative path (`shasum -a 256 <file>` prints that line). A shipped migration never
# changes: a database that ran it has recorded its checksum, and Flyway refuses that database when the
# file differs. ReleasedMigrationsTest in streamrune-core fails when a listed file differs from its
# checksum, and, once the newest entry of CHANGELOG.md is dated, when a migration is not listed. The
# pull request that dates an entry lists the migrations that release ships (the header of
# .github/workflows/release.yml lists the steps of a release).
