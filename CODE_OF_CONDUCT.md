# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

We want StreamRune's issues, pull requests and discussions to be welcoming, respectful and
focused on the work. Harassment, personal attacks and discriminatory language are not tolerated.

Report unacceptable behaviour to **licensing@streamrune.com**. Reports are handled confidentially.
